# H2MultiSim
H2MultiSim™ is an open-source, pure-Python toolkit for simulating underground hydrogen storage (UHS) across four scales: 0D; lumped material balance, 1D: radial finite-volume, 2D: areal Cartesian, and 3D: field-scale Cartesian. The toolkit is designed for researchers, engineers, and students for quick, reproducible UHS simulation.
